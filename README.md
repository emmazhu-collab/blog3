# Blog 3: Education and Unemployment

## Question

How does unemployment differ by education in the United States? Three figures ask whether the education gap persists over time, whether it remains within age groups, and what unemployment leaves out when people are outside the labor force.

## Data and method

The source is [IPUMS CPS](https://cps.ipums.org/cps/), Version 13.0. I use the Basic Monthly January samples for 2020–2026. The trend and age figures include civilians ages 25–64 in the labor force. The labor-status figure includes all civilian adults ages 25–64, including those outside the labor force.

Education is grouped into less than high school, high school, some college or an associate degree, and a bachelor's degree or higher. Employment status comes from `EMPSTAT`, and education comes from `EDUC`. Unemployed people include those on temporary layoff.

The script uses the person weight `WTFINL`. Within each group, the unemployment rate is `100 * weighted.mean(unemployed, WTFINL)`. This gives the weighted percentage of the labor force who are unemployed. For the status chart, the code sums weights for employed, unemployed, and not-in-labor-force adults, then divides by the total weight of each education group. These shares add to 100%. The unemployed share of all adults is not the unemployment rate. The figures describe January, not annual averages or seasonally adjusted rates.

## Get the data

1. Sign in to IPUMS CPS and select the January Basic Monthly samples for each year from 2020 through 2026. Do not select ASEC samples.
2. Include `YEAR`, `MONTH`, `AGE`, `EDUC`, `EMPSTAT`, and `WTFINL`.
3. Download the fixed-width data (`.dat.gz`) and its DDI dictionary (`.xml`). Put both in `data/raw/` folder.
4. The script expects `cps_00001.dat.gz` and `cps_00001.xml`. If your extract has a different name, update the two file paths in `code/analysis.R`. Use the dictionary that belongs to your downloaded extract.

Raw CPS microdata are excluded from Git. Other readers need to download their own extract under the [IPUMS terms](https://cps.ipums.org/cps/terms.shtml).

## Replication instructions

1. Download or clone this repository and open `blog3.Rproj` in RStudio.
2. Follow **Get the data** above if the two IPUMS input files are not already in `data/raw/`.
3. Install missing packages once:

   ```r
   install.packages(c("ipumsr", "tidyverse"))
   ```

4. From the project folder, run this in the R Console:

   ```r
   source("code/analysis.R")
   ```

Copy only the command inside the box into the R Console, without backticks, and press Enter. You can also open `code/analysis.R`, select all with **Command+A**, and click **Run**. Start from the first line, and keep the working directory at the main project folder.

The code reads the local extract, selects the analysis sample, creates the education and age groups, calculates weighted rates, and saves every table and figure below. It does not need an internet connection after packages and data are installed. It does not download data automatically.

From a terminal in the project folder, the equivalent command is `Rscript code/analysis.R`. The code creates `results/tables/` and `results/figures/` if needed, so existing results are not required to rerun the analysis.

## How the figures work together

The trend checks whether the education gap appears across years. The age panels compare people within the same age band: the bachelor’s-or-higher rate is lower than high-school and less-than-high-school rates in all four bands. Age composition alone therefore does not explain the observed gap. This is not a causal estimate, and the education ranking is not exact everywhere.

The status chart adds a different question: how many adults are employed, unemployed, or outside the labor force? It replaces the old January-only figure, which repeated the last point of the trend. Nonparticipation may reflect care work, school, retirement, or health, not only difficulty finding a job.

## Reading the results

`sample_n` is the number of survey observations in each group, not a population total. `rate` is the weighted unemployment percentage. In the status table, `weighted_people` is the sum of person weights and `share` is the percentage of all adults in that education group. The figures show differences between groups; they do not prove that education causes lower unemployment. Small groups have less precise estimates, and the analysis does not test statistical significance.
